# jellyseerr

The request front door for the media stack. Pick a film or show here and
everything downstream is already decided: Jellyseerr sends the request to Radarr
or Sonarr with a fixed quality profile and root folder, so nothing lands on the
unscored `Any` profile by accident.

Reachable at `https://jellyseerr.lab.skyhaven.ltd`.

## Why it exists

Radarr and Sonarr have no server-side default quality profile. Adding media
through their own UIs means picking one from a dropdown every time, and the
wrong pick is invisible until an 86GB Remux turns up in the download client.
Jellyseerr's service configuration is the only place that choice can be pinned
declaratively.

## How the service links are configured

`jellyseerr-reconcile-services` runs as an Argo CD `PostSync` hook. It reads
Jellyseerr's generated API key from `settings.json` on the config volume,
resolves the quality profile IDs by *name* from Radarr and Sonarr (IDs are not
stable across rebuilds), and creates or updates the two service links:

| Service | Quality profile     | Root folder            |
| ------- | ------------------- | ---------------------- |
| Radarr  | `HD Bluray + WEB`   | `/data/library/movies` |
| Sonarr  | `WEB-1080p`         | `/data/library/tv`     |

The profiles themselves are created by [`recyclarr`](../recyclarr/README.md), and
the size caps that stop a request becoming a 4K remux come from
[`buildarr`](../buildarr/README.md).

`buildarr-jellyseerr` is deliberately not used for this. Its Sonarr model
requires a `language_profile`, which Sonarr v4 removed, so it cannot describe a
v4 instance at all.

## First run is manual

Jellyseerr's setup wizard cannot be automated — it needs an interactive sign-in
against the media server to create the admin account. On a fresh config volume:

1. Open `https://jellyseerr.lab.skyhaven.ltd` and complete the wizard.
2. Re-run the reconcile job:

```sh
kubectl -n jellyseerr delete job jellyseerr-reconcile-services --ignore-not-found
kubectl -n argocd patch app jellyseerr --type merge \
  -p '{"operation":{"sync":{}}}'
```

Until that happens the job exits with a message saying so, and retries on its
`backoffLimit`. Everything else about the app is declarative. The config volume
is covered by the nightly appdata backup, so a rebuild that restores it skips
the wizard entirely.

## Secrets

`jellyseerr-secrets` (native Secret): `RADARR_API_KEY`, `SONARR_API_KEY`.
Projected from Azure Key Vault (`homelab-<service>-api-key`) by the
`argocd_bootstrap` Ansible role on every platform deploy. Jellyseerr's own API
key is generated by the app and read off the config volume — it is not in Key
Vault.
