# app-stockalert-monitor

Self-hosted stock alert monitor with a web-managed product list that sends a high-priority push notification via ntfy (with optional Telegram) when an item transitions from out of stock to in stock. Retailer parsers are resolved automatically from each URL's domain, with tuned UK retailer plugins and a generic detector for other shops. Runs alongside FlareSolverr for sites that require browser-based fetching.
